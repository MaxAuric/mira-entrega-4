# MIRA · Entrega 4: Sistema Multiagente para Ingeniería de Software

Repositorio oficial del **Entregable 4** del proyecto **MIRA** (*Taller de Desarrollo de Software Conducido por Agentes de IA*, Escuela de Ingeniería Informática, Universidad de Valparaíso).

## Estructura del Proyecto

```text
.github/
  agents/                   # Definición de los 4 agentes (.agent.md)
  skills/                   # Skills reutilizables (SKILL.md + recursos nivel 3)
  copilot-instructions.md   # Contexto global de MIRA y convenciones del repositorio
docs/
  decision.md               # Patrón de coordinación, agentes, herramientas y justificación
  bitacora.md               # Registro de corridas, carga de skills, fallas MAST y cambios
  trabajo/                  # Archivos de traspaso entre agentes
  evidencia/                # Capturas, logs y salidas de la corrida entregada
  linea-base/               # Corrida comparativa con un solo agente
src/                        # Código fuente de MIRA (Backend y Frontend)
tests/                      # Suite de pruebas automatizadas
README.md                   # Guía de ejecución rápida (< 15 minutos)
```
